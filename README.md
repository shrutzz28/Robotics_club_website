Features
The website is organized into 8 core components:
Home: A high-impact landing page featuring a hero section and the club's primary mission.
About Us: Detailed information regarding the club’s history, vision, and core values.
Robotic Animations: Custom-built mechanical animations powered by vanilla CSS and JS to simulate robotic movements.
Projects: A showcase of current builds, including technical specifications and development stages.
Workshop/Labs: A section detailing the tools, hardware, and software environments used by members.
Events: A responsive timeline of upcoming competitions, hackathons, and community outreach.
Membership: Information on recruitment, roles, and a functional join-us form.
Contact: A dedicated section for inquiries with integrated social media links and location details.
Technical Implementation
100% Vanilla: Built strictly with index.html, style.css, and script.js.
Fluid Responsiveness: Uses CSS Media Queries and Flexbox to ensure compatibility with all screen sizes in 2026.
Lightweight Animations: Smooth, hardware-accelerated animations implemented without heavy external libraries like GSAP.
Semantic HTML: Optimized for accessibility and SEO best practices.
